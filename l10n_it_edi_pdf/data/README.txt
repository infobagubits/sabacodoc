# Cartella data/

Inserire qui il file **FoglioStileAssoSoftware.xsl** prima di installare il modulo.

Il foglio di stile XSLT ufficiale per la visualizzazione delle fatture elettroniche
italiane è scaricabile gratuitamente dal sito di AssoSoftware:

    https://www.assosoftware.it/allegati/assoinvoice/FoglioStileAssoSoftware.zip

Dopo aver scaricato e decompresso lo zip, copiare il file .xsl in questa cartella:

    l10n_it_edi_pdf/data/FoglioStileAssoSoftware.xsl

Il modulo cercherà il file esattamente con questo nome.
